# Cafe Management System ☕

## Project Description
The Cafe Management System is a Java application developed for an Object-Oriented Programming (OOP) assignment. It manages basic cafe operations, including table availability, opening hours, and daily sales.

## OOP Concepts
- Classes and Objects
- Encapsulation
- Default and Parameterized Constructors
- Getter and Setter Methods
- Arrays
- Selection Structures (`if-else` and `switch`)
- Looping Structures (`for` and `while`)

## System Features
1. Check cafe opening status
2. Seat customers
3. Free occupied tables
4. Record daily sales
5. Display cafe information

## How to Run
1. Download the repository.
2. Open the project in Visual Studio Code.
3. Open the terminal.
4. Compile the Java program using `javac Main.java`.
5. Run the program using `java Main`.

## Programming Language
Java
